Binder Town Boss Timer

เว็บติดตามเวลาบอส พร้อมเสียงแจ้งเตือนสำหรับเกม Binder Town
โดยสามารถเข้าเล่นเกมได้ที่ Binder Town

🚀 เวอร์ชันบนเว็บไซต์

ความสามารถ

  • แสดงบอส Elite, Mini-Boss และ Field Boss พร้อมเวลานับถอยหลัง
  • ตั้งเวลาเกิดบอสและบันทึกเวลา
  • แจ้งเตือนด้วยเสียงเมื่อบอสใกล้เกิด

รันบนเครื่อง (Local)

ต้องติดตั้ง Node.js ก่อน จากนั้นเปิด Terminal ในโฟลเดอร์ repository แล้วรันคำสั่ง: 

cd Boss-Timer
npm install
npm start

จากนั้นเปิด http://localhost:3000 เพื่อใช้งาน

หากเปิดผ่าน GitHub Pages ระบบจะแสดงข้อมูลบอสและบันทึกเวลาไว้เฉพาะในเบราว์เซอร์นี้ เพราะ GitHub Pages ไม่รองรับเซิร์ฟเวอร์ Node.js
