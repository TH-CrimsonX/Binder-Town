## เครื่องมือ (Tools)

- **Build Simulator** — [เปิดหน้านี้](https://TH-CrimsonX.github.io/Binder-Town/Tools/Build-Simulator/) · จำลองการสร้างบิลด์ทั้งชุด: ออฟชั่นอุปกรณ์, จารึก, การ์ด และสรุปสเตตัสรวมในหน้าเดียว
- **Gear Simulator** — [เปิดหน้านี้](https://TH-CrimsonX.github.io/Binder-Town/Tools/Gear-Simulator/) · ตัวละคร + กระเป๋าไอเทมแบบในเกม ลากเลเวลคำนวณ Tier แล้วเลือกออฟชั่นสวมใส่ได้ทันที
- **Card Simulator** — [เปิดหน้านี้](https://TH-CrimsonX.github.io/Binder-Town/Tools/Card-Simulator/) · ทดลองใส่การ์ด 9 ช่อง ดู Resonance และ Spirit Load พร้อมค้นหาเส้นทางการ์ดทุกใบ
- **Boss Timer** — [เปิดหน้านี้](https://TH-CrimsonX.github.io/Binder-Town/Tools/Boss-Timer/) · ตัวนับเวลาเกิดบอส Elite / Mini-Boss / Field Boss พร้อมเสียงแจ้งเตือนและบันทึกเวลา

- **Map** — [เปิดหน้านี้](https://TH-CrimsonX.github.io/Binder-Town/Data/Map/) · แมพทุกภูมิภาค พร้อมลักษณะมอนประจำแมพ (Threats)
- **Patch Note** — [เปิดหน้านี้](https://TH-CrimsonX.github.io/Binder-Town/Data/Patch/) · สรุปการอัปเดตล่าสุดของเกม
- **Image Detector and Notification** — [เปิดหน้านี้](https://TH-CrimsonX.github.io/Binder-Town/Image-Detector-and-Notification/) · ตรวจจับไอคอนในหน้าจอเกมและแจ้งเตือนด้วยเสียง

## รันบนเครื่อง (Local)

โปรเจกต์เป็นเว็บแบบ static ไม่ต้องติดตั้งอะไรเพิ่ม เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย

หากต้องการรันผ่านเซิร์ฟเวอร์ (แนะนำ สำหรับ Boss Timer) ให้ติดตั้ง [Node.js](https://nodejs.org/) ก่อน แล้วรัน:

```powershell
node serve.mjs
```

เปิด <http://127.0.0.1:8899> เพื่อใช้งาน

ส่วน Boss Timer สามารถรันด้วย Express เพื่อซิงก์ข้อมูลบอสระหว่างผู้เล่นได้:

```powershell
cd Tools/Boss-Timer
npm install
npm start
```

เปิด <http://localhost:3000> เพื่อใช้งาน

> หากเปิดผ่าน GitHub Pages ระบบจะแสดงข้อมูลบอสและบันทึกเวลาไว้เฉพาะในเบราว์เซอร์นี้ เพราะ GitHub Pages ไม่รองรับเซิร์ฟเวอร์ Node.js

│   ├── app.js
│   └── styles.css

    │   ├── image/
